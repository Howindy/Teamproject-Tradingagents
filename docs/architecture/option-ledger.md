# FR-01 / CR-01 Option Ledger

Status: **personal draft / pending team review**

Each entry records a design question, the options considered, the choice, and
the evidence. Status: **chosen** (proposed in this draft), **rejected**, or
**open** (awaiting human decision). Chosen entries remain proposals until the
team approves D1/D2.

## A. Decided options

| ID | Question | Options considered | Choice | Rationale | Evidence | Status |
|---|---|---|---|---|---|---|
| O-01 | Who computes derived financial metrics? | Model (prompt only); model with a second-model verifier; deterministic code | Deterministic code | Removes the wrong-period error class; fixed expected values; offline tests | EL-03, EL-05, ADR-003 §3 | Chosen |
| O-02 | Where does the calculation live? | Inside vendor statement output; new router vendor method; separate service | Separate service with pure calculator and I/O adapter | Keeps the vendor's filed-values contract; avoids results changing with vendor fallback; pure core is testable | ADR-003 §3 C-D | Chosen |
| O-03 | How do agents receive the values? | Tool only; appended block only; both | Both | Tool serves the analyst while writing; block reaches every downstream reader regardless of tool use | ADR-003 §3 E-G | Chosen |
| O-04 | How is the comparison period found? | Column position; end date | End date and span (POL-DM-01) | Quarterly tables lack Q4 and contain duplicates | EL-04 | Chosen |
| O-05 | How are missing Q4 comparisons handled? | Derive Q4 by subtraction; report n/a | n/a with reason | A subtracted figure is not stated by any filing; the vendor already refuses to derive it | EL-04, `sec_edgar.py` L248 | Chosen |
| O-06 | Which P/E definition? | FY EPS; TTM EPS; both | Both, labeled | The two differ materially (44.3x vs 27.4x) | EL-09 | Chosen |
| O-08 | Main NFR | Literal-match share as a quality requirement; token cost of downstream context | Token cost (CR-01) | Historical token cost motivates bounded context; acceptance is limited to offline size and preservation checks | EL-01, EL-11 | Chosen |
| O-10 | When is downstream context reduced? | Only near a token limit; always | Always, for analyst reports in five downstream calls | Downstream prompts (11k-17k tokens) never approach the limits | EL-12 | Chosen |
| O-11 | How is the brief produced? | Fixed truncation; LLM summarizer node; fundamentals report only; analyst brief with deterministic extraction and fallback | Analyst brief with extraction and fallback | No extra calls; size and gap retention enforced by code; truncation drops conclusions; fundamentals-only drops price levels and events | ADR-003 §4 | Chosen |
| O-12 | Brief size | 1,000 / 2,000 / 3,000 / 4,000 characters | 2,000 (provisional) | Keeps about eight figures with periods while saving an estimated 29%-33% of input | EL-13 | Chosen |
| O-13 | Behavior when brief handling fails | Fail closed (empty brief); fail open (full report) | Fail open | Losing one call's saving is safer than an empty or truncated report | Blueprint §8 | Chosen |
| O-15 | Sentiment report brief | Brief block in its prompt; fallback condensation | Fallback condensation | Structured output would need a schema change; shortest report (6,502 characters) | EL-15 | Chosen |
| O-16 | Historical token-cost observation | Total run input; input of the five downstream calls | Totals are historical context, not a new reduction gate | Live token savings are not evaluated in this revision | BO-06, BO-07 | Chosen |
| O-17 | Origin of test reference values | Generated by the coding agent; specified by a team member | Specified by a team member in the agent task specification | Prevents circular verification | R-09 | Chosen |
| O-18 | Marker format | Plain headings; HTML comments with version | HTML comments with version | Invisible when rendered; version allows format changes | Blueprint §5 | Chosen |
| O-19 | Brief for the Trader | Brief; full market report | Full market report | The Trader converts price levels into entry and stop values | Blueprint §3 | Chosen |
| O-20 | Instruments without a gross-profit line | Substitute formula; n/a | n/a, reason "line item not filed" | No industry-specific formulas in version 1 | POL-DM-04 | Chosen |
| O-21 | Display precision | Raw floats; fixed precision | 1 decimal for percentages and multiples, 2 for ratios, integer USD millions | Stable text for byte-identical tests; readable | POL-DM-05 | Chosen |
