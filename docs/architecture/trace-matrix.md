2. **FC coverage.** The active FC table contains all 27 active FCs: FR-01 5, FR-03 5, FR-04 5, SB-01 5, INV-01 3, SR-01 4. The 28 deferred FCs remain future conditions and are not activated.
3. **No duplicate acceptance.** INV-01-FC01 may reuse the SB-01-FC05 output evidence; The future SR-02/FR-02/FR-05 evidence is not current acceptance. This avoids creating a second acceptance regime for the same behavior.
4. **No invented evidence.** No test function, test output, measurement, approval, report, or runtime observation is claimed except the recorded Round 1 C-08 core (`test/offline/test_fr04_risk.py`, RM-7-R1) and Round 2 C-09 core (`test/offline/test_sb01_final_check.py`, RM-10-R1). Other planned `T-*` identifiers are descriptive only. `R02-01` through `R02-11` are specification scenario groups; the user-reported targeted execution collected 99 cases (`99 passed in 0.58s`), not an FC count.
5. **Runtime monitoring.** Monitoring uses only existing/proposed design observables: availability summary and report region, risk result, SB-01 formal fields, existing safe warnings. No periodic scan, alert backend, metrics service, trace database, audit ledger, or new warning file is added.
6. **No independent monitor cases.** FR-01 has no reuse-hit metric; INV-01 has no continuous cross-output equality monitor; the FR-04 and C-09 cores are verified only at their callable boundaries while production SB-01 wiring remains unimplemented; new stats propagation is deferred; deferred requirements have no current monitoring. In those cases the deterministic execution boundary plus the planned offline evidence is the stated verification method.
7. **Deferred boundary.** Context budgets, compression thresholds, and compressed-constraint reinjection remain deferred by ADR 001 D-10c and are absent from this matrix's implementation, acceptance, and monitoring columns. FR-02, FR-05, SR-02, FR-06, FR-07, PR-01, and CR-01 remain deferred.
8. **Open verification impact.** Deferred OQ-16 affects future FR-02-FC03/FC05 and IR-15; OQ-12 affects FR-03-FC01; OQ-13 affects FR-01-FC05 and FR-03-FC05; OQ-15 affects FR-03-FC04/FC05 and IR-10/IR-13. These are evidence gaps, not new requirements or new architecture decisions.
