## 2. Existing conflict and reason for the amendment

The original plan §5 permits two existing-test adaptations but omits `test/offline/test_portfolio_context.py`. That file contains:

`test_completed_run_clears_the_checkpoint_it_wrote`

The test builds a portfolio-bearing graph, derives `written = graph._run_signature("stock", book)`, intercepts `clear_checkpoint`, calls `_run_graph(...)`, and expects `cleared == [written]`. Its original purpose is to ensure automatic cleanup uses the same portfolio signature as checkpoint creation.

Round 3 instead requires both default entries to execute afresh without acquiring, reading, resuming, or clearing old checkpoints, including when checkpointing is configured. Retaining the automatic-clear assertion contradicts that approved behavior; restoring automatic cleanup to satisfy it would contradict the original specification. Conversely, changing this omitted test without supplemental scope approval would exceed the original file allowance.

The user-provided implementation report identifies this conflict as a remaining regression failure. This document specifies the proposed correction; it does not claim the correction has been applied or passed.
